# MediDesk complete src

This package is a clean replacement for the project's `src` directory.

Important:
- Keep your existing `.env` outside this package and restore it under `src/backend/.env`.
- Keep the existing PostgreSQL database.
- Do NOT copy the Python `venv` into this package.
- Install frontend dependencies with `npm install` inside `src/frontend`.
- Backend runs with the existing Python virtual environment.
